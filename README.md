# SatuSaldo 💰🌱

> **Platform Finansial Terpadu** untuk melacak dan mengelola semua arus kas di rekening bank, e-wallet, dan uang tunai secara *real-time* dalam satu dashboard.

---

## 🌟 Fitur Utama
- **Multi-Dompet Terpadu**: Integrasi saldo Bank, E-Wallet, dan Kas Tunai.
- **Modern "Frosty Mint" Aesthetic**: Antarmuka bersih, responsif, dan elegan dengan gradasi warna yang halus serta visual glassmorphism modern.
- **Tracking Otomatis & Real-time**: Visualisasi total kekayaan bersih dan ringkasan keuangan dalam hitungan detik.

---

## 🛠️ Tech Stack
- **Frontend**: [Vue 3](https://vuejs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Routing**: [Vue Router 4](https://router.vuejs.org/)
- **State Management**: [Pinia](https://pinia.vuejs.org/)
- **Typography**: Outfit & Plus Jakarta Sans

---

## 🚀 Memulai (Development)

1. **Clone repository**:
   ```bash
   git clone https://github.com/HanifAF/satusaldo.git
   cd satusaldo
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   npm run dev
   ```
   Buka `http://localhost:5173` di browser Anda.
